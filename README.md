# Корги против Биглей — 3D шашки

Шашки на React и Three.js: бигли против корги. Международные 10×10 и русские 8×8, игра с ботом или вдвоём, 3D- и 2D-доска, задачи-комбинации.

## Основные возможности

- Два вида шашек: международные 10×10 (правило большинства, турецкий удар, превращение только в конце хода) и русские 8×8 (свободный выбор серии, превращение посреди взятия).
- Соперник — бот трёх уровней или второй игрок на том же устройстве; против бота можно играть за любую сторону.
- Отмена хода, подсказка лучшего хода, запись партии в нотации (номера полей 1–50 или `c3:e5`) с копированием.
- Партия сохраняется автоматически и продолжается из главного меню.
- Задачи: позиции, где нужно найти форсированный выигрыш; неверный ход отклоняется, решённые отмечаются.
- 3D-сцена на React Three Fiber и плоская 2D-доска; при сбое WebGL игра сама переходит на 2D.
- Управление с клавиатуры, звуки (синтез WebAudio, без файлов), полноэкранный режим.
- Правила ничьей: повторение позиции, ходы только дамками, эндшпиль против одинокой дамки — по правилам каждого вида.
- Бот считает в Web Worker, учитывает повторения и правило ходов дамками, не подвешивает интерфейс.

## Технологии

- React 19 + TypeScript
- Vite 8
- Three.js, React Three Fiber, @react-three/drei
- Zustand для состояния партии, анимаций и производительности
- Tailwind CSS 4
- Vitest, oxlint, Prettier

## Быстрый старт

1. Установите Node.js 22.12+ (CI использует Node 24).
2. Установите зависимости: `npm install`
3. Запустите dev-сервер: `npm run dev`
4. Откройте адрес из консоли (по умолчанию <http://localhost:5173>). Сервер стартует с `--host`, поэтому доступен и по локальной сети.

## Структура проекта

```text
src/
  engine/     правила без React: доска, варианты правил, генерация и применение ходов, ничьи, нотация
  ai/         оценка позиции, поиск (negamax + альфа-бета + таблица транспозиций), решатель задач, Web Worker
  match/      партия: стор, настройки, сохранение, задачи, выбор хода по шагам, ход бота, анимации
  scene/      3D: доска, клетки, фигуры, окружение (environment/), FPS
  ui/         меню, HUD, 2D-доска (board2d/), модалки, звук, клавиатура, настройки вида
  shared/     константы (в т.ч. пресеты ИИ), типы, логгер, localStorage
tests/        тесты, повторяющие структуру src, и хелперы (helpers/)
public/
  models/     GLB фигур и короны (сжаты meshopt)
  textures/   текстуры клеток, рамки и облаков
```

Зависимости направлены в одну сторону: `shared ← engine ← ai ← match ← scene/ui`. Между слоями импорт идёт через алиас `@/…`, внутри слоя — относительными путями.

Ключевые понятия:

- **`PieceMove`** — ход целиком: откуда, все остановки (`path`), побитые фигуры (`captures`) и превращение (`promotes`).
- **`RuleOptions`** — вариант правил: размер доски, правило большинства, превращение посреди взятия, лимиты ничьей. Движок и ИИ работают только через них.
- **`revision`** в `gameStore` меняется при каждом ходе, отмене и новой партии. Ход бота и подсказка проверяют его после каждого ожидания, поэтому устаревший результат не попадёт в позицию.
- **История** хранит позицию до каждого хода — на ней построены отмена, запись партии и сохранение (сохраняются только ходы, при загрузке они проигрываются через движок).

## Геймплей и правила

- Бигли ходят первыми. Против бота выберите сторону в меню; при игре за корги 2D-доска разворачивается к вам.
- Простая шашка ходит вперёд на соседнее поле, а бьёт и вперёд, и назад. Дамка ходит и бьёт на любое расстояние.
- Взятие обязательно, серию нужно довести до конца. Побитые фигуры снимаются после хода: через одну фигуру нельзя прыгнуть дважды.
- Международные: из нескольких серий выбирается та, что бьёт больше фигур; шашка становится дамкой, только закончив ход на последней горизонтали.
- Русские: правила большинства нет; шашка, дошедшая до последней горизонтали во время взятия, сразу бьёт дальше как дамка.
- Ничья: троекратное повторение; 25 (международные) или 15 (русские) ходов только дамками без взятий; против одинокой дамки — 16 или 5 ходов (международные), 15 ходов при трёх дамках против одной (русские).
- Режимы: классика, «Безумные прыжки» (простая шашка после взятия может встать на любое поле за фигурой), «Вечеринка» (эффекты), «Турбо» (бот без пауз).
- Клавиатура: стрелки — курсор, Enter/пробел — выбрать, Esc — снять выбор, Z — отменить ход, H — подсказка.

## Настройки и кастомизация

- `src/engine/rules.ts` — параметры вариантов правил.
- `src/shared/config/constants.ts` — пресеты ИИ (`AI_PRESETS`: глубина, бюджет времени, разброс выбора), паузы бота, пороги FPS.
- `src/ai/evaluate.ts` — веса оценки позиции.
- `src/match/puzzleData.ts` — задачи (диаграмма, кто ходит, за сколько ходов). Тест `tests/match/puzzles.test.ts` проверяет, что каждая решается ровно за заявленное число ходов единственным первым ходом.
- `src/ui/menuModeItems.ts` — карточки режимов и уровни сложности.
- `src/scene/environment/` — освещение, небо, облака, диско-шары.

## Производительность

- three.js загружается только для 3D-доски: меню и 2D-режим обходятся без него, 3D-чанк подгружается в фоне, пока открыто меню.
- Монитор FPS пишет замеры в `performanceStore`. Режим (`high` / `medium` / `low`) понижается после двух плохих замеров подряд, а повышается только после ~4 секунд стабильной работы.
- Материалы клеток создаются один раз и меняются на месте; облака — мягкие билборды (`Clouds` из drei с локальной текстурой), плитки диско-шаров — `InstancedMesh`.
- Модели фигур сжаты meshopt (декодер встроен в drei), модель корги упрощена до ~15 тыс. треугольников.
- Canvas: `dpr` [1, 1.5], `powerPreference: "high-performance"`.
